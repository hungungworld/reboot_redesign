# 알디콤 US 마케팅 대시보드: 시장 · 고객 인사이트 (담당: 현경)

미국 시장에서 알디콤의 **진열대(경쟁 제품·가격) · 고객 반응(리뷰·유튜브) · 검색 수요**를 매주·매월 모아 보여주고,
마케터가 할 일을 정리해 주는 대시보드입니다. 이 문서는 **3번째 대시보드**(업무 주기별 구성)를 기준으로 설명합니다.

> **이름 규칙:** 이 문서의 **알디콤**은 실제로 수집하는 자사 기준 제품이에요. 발표 화면에서는 리브랜딩 이름 **REBOOT**로 표기하고, REBOOT 젤리·음료 4종을 가상 출시했다고 가정해요. 시장·경쟁사·리뷰 데이터는 모두 실제예요. 자세한 내용은 설정 README를 보세요.

- **화면:** `web/` (HTML·CSS·JS)
- **서버:** `server.py` (Python). 데이터 수집과 AI 호출을 서버가 맡아요. 브라우저만으로는 API 키가 노출되고, 다른 사이트 수집이 막혀서예요.

---

## 실행

```bash
pip install -r requirements.txt
python server.py
```

http://localhost:8000 이 자동으로 열려요. 종료는 `Ctrl+C`.
사이드바 맨 위에서 **3번째 대시보드**를 고르세요. 마지막에 고른 버전이 기억돼요.

## API 키

**설정 › 연결**에서 키를 입력하는 게 기본이에요. 저장한 키는 끝 4자리만 보이고, 서버에 암호화해서 저장돼요.
`.env`에 넣어둘 수도 있어요. 화면에서 입력한 키가 `.env`보다 우선이에요. `.env`는 공유하지 마세요.

```
OPENAI_API_KEY=...
OPENAI_MODEL=gpt-5.4-mini      # 선택 (기본 gpt-5.5)
YOUTUBE_API_KEY=...
FIRECRAWL_API_KEY=...
SERPAPI_KEY=...
```

| 키 | 쓰는 곳 | 무료 한도 | 없으면 |
|---|---|---|---|
| `OPENAI_API_KEY` | 이번 주 액션, 한 줄 정리, 한국어 정리, 리뷰 분류, 월간 요약·전략 | 유료 (사용량 과금) | AI 기능이 꺼져요 |
| `FIRECRAWL_API_KEY` | Weee! 진열대 (목록·가격·재고·핵심 메시지) | 월 1,000 크레딧 (학생 1만) | Weee! 수집이 안 돼요 |
| `SERPAPI_KEY` | Amazon 진열대·대표 리뷰, Google 검색 트렌드 | 월 250회 | 검색 트렌드는 Google Trends CSV로 대체 |
| `YOUTUBE_API_KEY` | 유튜브 영상 검색·댓글 (월간) | 하루 10,000 units | 비공식 대체 경로 (시연용) |

키 상태와 남은 사용량은 **설정 › 연결**에서 테스트할 수 있어요. 키 입력·암호화, Gmail 로그인은 설정 README를 보세요.

## 3번째 대시보드 한눈에 보기

```
시장 · 고객 인사이트
├── 주간 리뷰 ──── 매주 월요일 · 15분 · "이번 주 무엇을 해야 하나"
├── 월간 리뷰 ──── 매월 첫 주 · 1시간 · "지난 한 달 무엇이 달라졌나"
└── 데이터 ─────── 필요할 때 · 숫자의 원본과 근거
설정
├── 수집 설정 ──── 검색어 세트 · 영상 선정 기준 · Amazon 검색어/추적 ASIN · 트렌드 키워드 · 시즌
├── 제품 정보 ──── 브랜드 기본 정보 · REBOOT 4종 팩트시트 (기사·공식 정보 기반 / 가격·원가는 가상값)
├── 연결 ────────── API 키 입력 · 연결 테스트 · Gmail 로그인
└── 작업 로그 ──── 수집 · AI 프롬프트 · 승인 기록(자동/수동) (과제 제출용)
```

설정 탭의 자세한 내용은 설정 README에 있어요. 알디콤의 **실제 판매가**는 팩트시트가 아니라 이 탭(진열대)에서 수집해 보여줘요.

### 주간 리뷰 (매주 월요일)

| 영역 | 내용 |
|---|---|
| **이번 주 액션** | 판단은 **규칙**이 하고, AI는 문장만 써요. 신호마다 **긴급 / 기회 / 참고** 등급과 **사실 → 왜 중요한가 → 할 일**을 보여줘요. 걸린 신호가 없으면 "특이사항 없음"이에요. |
| 진열대 변화 | 품절 · 가격 변동 · 신규 진입 수, Weee!에서 알디콤의 1회분 단가 위치 |
| 새 리뷰 | 지난 7일 새 리뷰 수, 칭찬·불만 상위 주제 |
| 다가오는 시즌 | D-day, 작년 검색 최고점 (캠페인 기획은 캠페인 준비 탭에서) |

**이번 주 액션 규칙**
- 알디콤 품절 + 45일 안에 시즌 → 긴급
- 경쟁사 가격 ±10% 이상 변동 → 인하는 긴급, 인상은 참고
- 신규 제품 진입 → 참고
- 작년에 검색이 평균보다 20% 이상 늘었던 시즌이 30일 안에 옴 → 기회
- 잠재 고객 최다 질문 → 기회
- 알디콤 리뷰 불만 1위 → 긴급

**버튼**
- **데이터 업데이트:** 확인 창에서 항목을 고르고, 비용과 이번 달 남은 사용량을 본 뒤 시작해요. 항목은 Weee! 진열대 · Amazon 진열대·리뷰 · 검색 트렌드 · 리뷰 분류 · 이번 주 액션이에요.
- **주간 리포트 받기:** Word 1장

### 월간 리뷰 (매월 첫 주 · 1~7일에는 지난달을 보여줘요)

| 영역 | 내용 |
|---|---|
| 이달의 요약 | AI 3줄 |
| 지표 4개 | 알디콤 품절 주수 · 경쟁사 가격 변동 횟수 · 새 리뷰 수 (알디콤/경쟁사 구분) · 검색 지수 (지난달 대비) |
| 고객 인사이트 | 3개. 펼치면 FAQ · 고객 표현 · 협업 후보 크리에이터 · 분류 정확도 |
| 경쟁사 동향 | 3줄. 주시 중인 경쟁사부터 다뤄요 |
| 전략 업데이트 | **지난달 대비 바뀐 점**, 페르소나 최대 3개 (한 줄 · 핵심 니즈 · 쓸 메시지), SWOT 칸당 3개, 타깃 1문장, 포지셔닝 1문장 |

**버튼**
- **월간 분석 실행:** 유튜브 수집 → VOC 분류 → 리뷰 분류 → 요약·전략. 항목별로 골라서 실행할 수 있어요.
- **월간 리포트 받기:** Word
- **데이터 받기:** Excel

### 데이터 (탭마다 "질문 제목 → 한 줄 정리 → 핵심 → 접어둔 원본")

| 탭 | 질문 | 핵심 화면 |
|---|---|---|
| 진열대 | 누가 얼마에, 무슨 말로 팔고 있나 | 1회분 단가 **$3 미만 / $3~6 / $6 이상** 묶음. 알디콤 초록, 주시 ★, 품절 빨강. 누르면 한국어 핵심 메시지·가격 계산·재고·판매 신호. "표로 보기" 안에 수집 버튼과 전체 표 |
| 경쟁사 | 누구와 경쟁하고 있나 | 직접 경쟁 / 카테고리 경쟁 / 대체재 3열 카드. 신호 3개(**같은 판매처 · 고객 언급 · 가격대 비슷**)가 많을수록 위. 한국어 근거 한 줄, "근거 보기"에 원문·출처. **주시하기**로 고른 브랜드는 다른 화면에서 먼저 보여요 (5~6개 추천) |
| 구매자 리뷰 | 고객은 무엇에 만족하고, 무엇에 실망하나 | 브랜드 × (효과 · 맛·향 · 복용 편의 · 부작용 · 가격) 비교표. +칭찬 / −불만을 누르면 한국어 요약 + 원문. 아마존 리뷰 요약, Weee! 리뷰 CSV 올리기 |
| 잠재 고객 (유튜브) | 사기 전에 무엇을 궁금해하나 | 자주 묻는 질문 · 자주 쓰는 표현 · 협업 후보 크리에이터, 각 Top 5. 댓글 원문과 수집 과정은 접기 |
| 검색 수요 | 언제 찾고, 왜 늘었나 | 다음 급등 예상 (작년 같은 시기 대비 %), 지난 12개월 급등과 이유, 12개월 차트. 숫자 표는 접기. 시즌은 **설정 › 수집 설정**에서만 편집 |
| 정확도 검증 (고급) | AI 분류를 믿어도 되나 | 사람 정답 30건으로 규칙 / AI(예시 없이) / AI(예시 포함) 채점 → 이긴 방식으로 전체 분류 |

**한 줄 정리:** 데이터가 바뀌었을 때만 AI가 다시 써요. 같은 데이터면 저장된 문장을 보여줘서 비용이 들지 않아요.

## 데이터는 어디서 오나

| 데이터 | 방법 | 주기 | 알아둘 점 |
|---|---|---|---|
| Weee! 진열대 | Firecrawl: 숙취 카테고리 2페이지 + 주요 상품 페이지 10개 (재고·핵심 메시지) | 주 1회 | 카테고리는 매번 보이는 제품이 달라서 알디콤은 상품 페이지로 따로 수집. 음식(해장국)은 제외 |
| Amazon 진열대 | SerpApi: "hangover" · "korean hangover" 검색 상위 (광고 제외 각 8개) + 많이 팔린 6개 상품 조회 | 주 1회 | **알디콤은 아마존 검색에 나오지 않아요 (2026-10-23 기준).** ASIN을 알면 수집 설정 › 추적 ASIN에 넣으세요 |
| 구매자 리뷰 | Amazon: SerpApi 상품 조회의 대표 리뷰 8개 + 아마존 리뷰 요약 / Weee!: CSV | 주 1회 | Weee!는 상품 페이지에 리뷰가 없어서 수동이에요. 아마존은 전체가 아니라 **대표 리뷰** 기준이에요 |
| 검색 수요 | SerpApi Google Trends (미국 · 12개월) | 주 1회 | 키워드마다 **따로 조회** — 같이 조회하면 큰 키워드가 작은 키워드를 납작하게 만들어요 |
| 잠재 고객 | YouTube Data API: 검색어 세트 A(제품 리뷰) · B(숙취 일반) · K(한국 숙취해소제) + 영상 선정 기준 | 월 1회 | 무관한 댓글(유튜버 칭찬·잡담)은 AI가 걸러요 |
| 경쟁사 후보 | 사전 조사 + AI 웹 검색 (근거 출처 포함) | 필요할 때 | AI 근거가 엉뚱할 수 있어요 → "근거 보기"로 출처를 꼭 확인 |

**1회분 단가 계산**
- **기본:** 포장 문구에서 개수를 읽어 계산해요. 예) `5 pack*4 boxes` = 20, `Pack of 6` = 6, `(min 2)`는 최소 주문 수량이라 무시
- **보충:** 문구에서 못 읽으면 한국어 이름("20팩")에서 가져와요. 한 번 확인된 개수는 기억해요.
- **수정:** 틀리면 진열대 › 표로 보기에서 바로 고칠 수 있어요.

## 알려진 한계

- **변화 알림은 2주차부터:** 가격·품절·신규 알림과 월간 지표는 주간 데이터가 쌓여야 의미가 생겨요. 첫 주에는 비교할 지난주가 없어요.
- **회분 수 확인 필요:** 큐원 망고 젤리, 지바이오틱스, 블로피쉬는 묶음 구성을 확인하지 못해 1회분으로 잡혀 있어요.
- **알디콤 1박스 구성 불일치:** Weee! 상품 페이지 "21 ml × 4 Sachets"와 목록 "1 pack*5 pack"이 달라요. 지금은 4포 기준이에요.
- **경쟁사 공식 사이트 크롤링은 뺐어요:** 3번째 대시보드에서는 쓰지 않아요. 판매처 페이지가 봇 접근을 막아 내용을 가져오지 못했어요.
- **AI 문장은 근거 데이터와 함께 확인하세요:** 판단 규칙과 AI에 넘긴 사실은 "규칙에 걸린 신호 보기" · "근거 보기"에서 볼 수 있어요.
- **검색 트렌드의 이유는 추정이에요:** 급상승 검색어가 급등한 그 주가 아니라 12개월 전체 기준이에요.

## 다른 버전 (사이드바 토글로 비교)

| 버전 | 구성 | 코드 |
|---|---|---|
| 3번째 대시보드 | 이 문서 내용 (주간 · 월간 · 데이터 · 수집 설정) | `web/v3.js` · `web/v3data.js` · `lib/v3.py` · `lib/v3data.py` |
| 새 대시보드 | 미국 시장 인사이트 한 화면 (① 이번 주 체크 · ② 진열대 · ③ 고객 반응 · ④ 수요 타이밍) | `web/dash.js` · `lib/market.py` |
| 기존 버전 | 1~6단계 (VOC 수집 → 분류·검증 → 분석 → 페르소나 → 경쟁사 → SWOT·STP) | `web/app.js` · `lib/analysis.py` 등 |

세 버전은 같은 `data/`를 함께 써요. 한 버전에서 수집하거나 분류하면 다른 버전에도 반영돼요.
3번째 대시보드는 기존 기능을 **호출만** 하고, 기존 화면 내용은 바꾸지 않아요.
