# REBOOT US 마케팅 대시보드: 설정 (담당: 현경)

다른 탭들이 함께 참조하는 **기준값**을 모아 관리하는 곳이에요.
수집 기준, 제품 정보, 외부 서비스 연결, 작업 기록을 여기서 정하고 확인해요.

> **이름 규칙**
> - **알디콤**: 출발점이 된 실제 기업이에요. 아마존·Weee! 등에서 수집하는 실제 데이터의 기준 제품이에요.
> - **REBOOT**: 발표용 리브랜딩 이름이에요. 회사명·제품명 모두 REBOOT로 표기하고, **젤리·음료 4종을 가상으로 출시했다고 가정**해요.
> - 시장·경쟁사·리뷰 정보는 실제 데이터를 쓰고, REBOOT 4종의 가격·원가만 가상값이에요.

```
설정
├── 수집 설정 ──── 검색어 세트 · 영상 선정 기준 · Amazon 검색어/추적 ASIN · 트렌드 키워드 · 시즌
├── 제품 정보 ──── 브랜드 기본 정보 · REBOOT 4종 팩트시트 (기사·공식 정보 기반 / 가격·원가는 가상값)
├── 연결 ────────── API 키 입력 · 연결 테스트 · Gmail 로그인
└── 작업 로그 ──── 수집 · AI 프롬프트 · 승인 기록(자동/수동) (과제 제출용)
```

| 메뉴 | 입력 방식 | 누가 쓰나 |
|---|---|---|
| 수집 설정 | 화면에서 편집 | 시장·고객 인사이트 |
| 제품 정보 | 화면에서 수동 입력 | 콘텐츠 제작 · 컴플라이언스 등 |
| 연결 | 화면에서 키 입력 / Google 로그인 | 모든 탭 |
| 작업 로그 | 자동 기록 | 과제 제출 |

화면 오른쪽 위 **변경 사항 적용**을 눌러야 저장돼요.

## 1. 수집 설정

시장·고객 인사이트 탭이 **무엇을, 어떤 기준으로 모을지** 정해요. 매주 바꾸는 값이 아니라 한 번 정해두고 필요할 때만 고치는 기준이에요.

| 항목 | 내용 | 쓰는 곳 (인사이트) |
|---|---|---|
| 검색어 세트 | A · 제품 리뷰 / B · 숙취 일반 / K · 한국 숙취해소제 | 잠재 고객 (유튜브) |
| 영상 최소 조회수 | 이 숫자보다 조회수가 낮은 영상은 제외 | 잠재 고객 (유튜브) |
| 영상 언어 | 영어 / 한국어 · 영어 | 잠재 고객 (유튜브) |
| Amazon 검색어 | 예) `hangover` · `korean hangover` | 진열대 · 구매자 리뷰 |
| 추적 ASIN | 검색에 안 나와도 꼭 따라볼 아마존 상품 번호 (알디콤 포함) | 진열대 · 구매자 리뷰 |
| 트렌드 키워드 | Google Trends로 조회할 키워드 (키워드마다 따로 조회) | 검색 수요 |
| 모니터링 시즌 | Halloween · Thanksgiving Eve · New Year's Eve | 주간 리뷰 · 검색 수요 |

- 시즌은 **여기서만** 고쳐요. 인사이트 › 검색 수요에서는 보기만 해요.
- 수집 설정을 바꾸면 **다음 데이터 업데이트부터** 반영돼요. 이미 모은 데이터는 그대로예요.

## 2. 제품 정보 (팩트시트)

AI가 콘텐츠를 만들거나 컴플라이언스를 검토할 때 기준으로 삼는 **제품 사실 정보**예요.

### 브랜드 기본 정보

| 항목 | 값 |
|---|---|
| 브랜드명 | REBOOT |
| 기준 기업 | 알디콤 (실제 데이터 출처) |
| 주요 시장 | 미국 · United States |
| 브랜드 소개 | 2025년 설립. 일상에 새로운 리추얼을 더하는 REBOOT. |

### REBOOT 4종 (가상 출시)

| 제품명 | 내부 코드 |
|---|---|
| Reboot 젤리 | RBT-J-01 |
| Reboot 저당 젤리 | RBT-J-02 |
| Reboot 음료 | RBT-D-01 |
| Reboot 저당 음료 | RBT-D-02 |

### 제품마다 적는 항목

| 항목 | 입력 기준 | 비고 |
|---|---|---|
| 제품 분류 | 예) 일반식품 | |
| 성분 · 용량 · 맛 | 알디콤 기존 제품의 **기사 · 공식 정보** | 출처 필수 |
| 섭취법 | 기사 · 공식 정보 | 출처 필수 |
| 소비자용 영문명 | 직접 정함 | 미정이면 "미정" |
| 가격 | **가상값** | 화면에 `가상값` 배지 |
| 원가 | **가상값** | 화면에 `가상값` 배지 |
| 출처 | 기사 · 공식 페이지 URL | 항목별로 기록 |
| 근거 상태 | 확인 필요 / 확인 완료 | 출처가 없으면 "확인 필요" |
| 최종 수정일 | 자동 기록 | |

### 규칙

- **실제와 가상을 섞지 않아요.** 성분·용량 같은 사실 정보는 기사·공식 자료로만 채우고, 가격·원가만 가상값을 써요.
- **가상 가격은 실제 시장을 참고해요.** 인사이트 › 진열대의 경쟁 제품 1회분 단가 구간($3 미만 / $3~6 / $6 이상)을 보고 정해요.
- 알디콤의 **실제 판매가**는 팩트시트에 넣지 않아요. 인사이트 탭이 Weee!·아마존에서 수집해 보여줘요.
- **내부 제품명은 광고 문구에 자동으로 쓰지 않아요.** "저당" 같은 이름이 효능·당류 주장처럼 보일 수 있어서, 소비자에게 보이는 문구는 컴플라이언스 검토를 거쳐요.

## 3. 연결

대시보드가 외부 서비스를 쓰기 위한 연결이에요. 배포 후 비개발자도 관리할 수 있도록 **화면에서 키를 입력**해요.

### 연결 목록

| 서비스 | 쓰는 곳 | 연결 방식 |
|---|---|---|
| OpenAI | 요약 · 카피 · 분류 (인사이트 등) | API 키 입력 |
| Firecrawl | Weee! 진열대 | API 키 입력 |
| SerpApi | Amazon 진열대·리뷰 · 검색 트렌드 | API 키 입력 |
| YouTube | 영상 검색 · 댓글 | API 키 입력 |
| Shopify | 할인코드별 주문 · 매출 | API 토큰 입력 |
| Gmail | 협업 메일 (인플루언서·파트너) | Google 로그인 |

각 키의 무료 한도와 한 번 돌릴 때 드는 비용은 인사이트 README의 **API 키** 표를 보세요.

### API 키 입력

1. **설정 › 연결**에서 서비스의 **키 입력**을 눌러 붙여 넣어요.
2. **연결 테스트**를 누르면 상태와 남은 사용량이 보여요.
3. 상태는 **정상 / 오류 / 미연결** 세 가지예요.

- 저장한 키는 다시 볼 수 없고 끝 4자리만 보여요 (`••••abcd`). 바꿀 때는 새로 입력해요.
- 키는 서버에 **암호화**해서 저장해요. 브라우저에는 저장하지 않아요.
- 화면에서 입력한 키가 `.env`보다 **우선**이에요. 화면에서 지우면 `.env` 값으로 돌아가요.

### Gmail 로그인

- **Google로 로그인**을 누르고 협업 메일에 쓸 계정을 고르면 연결돼요.
- 연결 해제는 같은 자리의 **연결 해제** 버튼으로 해요.
- 메일 발송은 인플루언서·파트너 탭에서 담당자가 내용을 확인한 뒤에 해요.

### 처음 한 번만 (개발 담당)

배포할 때 `.env`에 아래 값을 넣어둬야 화면 입력과 Gmail 로그인이 작동해요.

```
APP_SECRET_KEY=...          # 키 암호화용. 바꾸면 저장된 키를 다시 입력해야 해요
GOOGLE_CLIENT_ID=...        # Gmail 로그인용
GOOGLE_CLIENT_SECRET=...
```

API 키도 `.env`에 넣을 수 있어요 (인사이트 README 참고). 화면 입력이 없을 때 쓰는 기본값이에요.

### 보안 주의

- `.env`와 저장된 키 파일은 공유하거나 GitHub에 올리지 마세요.
- 발표 자료·스크린샷에 키가 보이지 않게 해요 (화면은 끝 4자리만 보여요).

## 4. 작업 로그

대시보드에서 일어난 일을 **자동으로 기록**해요. 과제 제출용 자료예요.

### 기록 종류

| 구분 | 언제 남나 | 예시 |
|---|---|---|
| 수집 | 데이터 업데이트 · 월간 분석 실행 | 주간 데이터 수집 |
| AI 프롬프트 | AI를 부를 때마다 | 리뷰 주제 분류, 이번 주 액션 문장 작성 |
| 승인 · 선정 | 규칙이 자동 처리했거나 사람이 고를 때 | 경쟁사 후보 확인, 주시 브랜드 선정 |

### 화면 열

| 일시 | 구분 | 작업 | 상태 | 승인 | 상세 |
|---|---|---|---|---|---|
| 10.23 09:00 | 수집 | 주간 데이터 수집 | 완료 | 자동 | 수집 건수 |
| 10.23 09:03 | AI 프롬프트 | 리뷰 주제 분류 | 완료 | 자동 | 프롬프트 보기 |
| 10.23 09:15 | 승인 · 선정 | 경쟁사 후보 확인 | 검토 대기 | – | 후보 목록 |

- **상태:** 완료 / 검토 대기 / 실패
- **승인:** `자동`(규칙이 처리) 또는 승인한 사람 이름. 검토 대기 중이면 `–`

### 프롬프트 로그 (상세)

AI 프롬프트 기록을 누르면 아래가 보여요.

- 사용한 탭 · 기능
- 모델
- 보낸 프롬프트 (입력)
- 응답 요약
- 사용량 (토큰)

### 내려받기

- **작업 로그 받기:** Excel (구분별 시트) · CSV
- 인사이트의 **데이터 받기 (Excel)** 에도 작업 로그 시트가 들어 있어요.

### 규칙

- API 키, 이메일 주소 같은 개인정보는 로그에 남기지 않아요. 프롬프트에 섞여 있으면 가려서 저장해요.
- 로그는 지우지 않아요. 제출 근거라서 수정·삭제 기능이 없어요.

## 구현 위치

인사이트 탭과 같은 서버(`server.py`)와 `data/`를 함께 써요.

| 메뉴 | 파일 | 상태 |
|---|---|---|
| 수집 설정 | `lib/v3.py` · `lib/youtube.py` | 있음 |
| 제품 정보 | 팩트시트 저장·조회 | 추가 예정 |
| 연결 | `lib/sources.py` (연결 테스트) · `lib/store.py` (키 저장) | 화면 입력 · 암호화 · Gmail 로그인 추가 예정 |
| 작업 로그 | `lib/store.py` | 승인 열 · 프롬프트 상세 · CSV 받기 추가 예정 |

## 알려진 한계

- **REBOOT 4종은 가상 제품이에요.** 실제 판매 데이터가 없어서, 판매 관련 숫자는 알디콤 실제 데이터 또는 가상값이에요.
- **키 암호화 값(`APP_SECRET_KEY`)을 바꾸면** 화면에서 입력한 키를 모두 다시 넣어야 해요.
- **Gmail은 Google 앱 검수 전이라** 테스트 사용자로 등록한 계정만 로그인할 수 있어요.
