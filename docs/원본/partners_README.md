# 🤝 인플루언서 · 파트너 관리 [P1]

REBOOT(숙취해소 기능성 음료) 미국 진출을 위해 인플루언서·케이터링 외주업체를 검색·컨택하고, AI 협업 제안 메일 발송, 협업 가이드 작성, 협업 이력 관리, 크리에이터별 판매 실적 분석을 하는 대시보드입니다.

- **담당자:** 혁주, 효선
- **우선순위:** P1
- **공동 작업:** 업체 컨택, 협업 제안 메일, 인플루언서·케이터링 가이드
- **구성:** Streamlit 대시보드(`app.py`) + Flask REST API(`server.py`) + 공통 로직(`core.py`)
- **요구사항 원문:** [REQUIREMENTS.md](REQUIREMENTS.md) — 기능 요구사항 명세 (다른 프로그램 문서와 병합용)

---

## 1. 빠른 시작

```bash
pip install -r requirements.txt
streamlit run app.py      # 대시보드 → http://localhost:8501
python server.py          # REST API → http://localhost:5000 (선택)
```

### `.env` 설정

| 키 | 설명 | 필수 |
| --- | --- | --- |
| `open_api` | OpenAI API 키 (메일·가이드 생성, 번역, 회신 요약, 답장 초안) | ✅ |
| `OPENAI_MODEL` | 사용 모델 (기본 `gpt-4o-mini`, 번역 품질을 높이려면 `gpt-4o`) | |
| `gmail_address` | 발송용 Gmail 주소 | ✅ |
| `gmail_api` | Gmail **앱 비밀번호** 16자리 ([발급](https://myaccount.google.com/apppasswords), 2단계 인증 필요) | ✅ |
| `APP_PASSWORD` | 대시보드 접속 비밀번호. 비워두면 로그인 없이 바로 접속 (배포 시 반드시 설정) | |
| `DATA_DIR` | 이력 DB·첨부파일 저장 경로 (기본 `./data`, Render는 `/var/data`) | |
| `PRODUCT_DESC` | AI 프롬프트에 들어가는 제품 설명 | |
| `REGULATION_DB_URL` | 규제(검열) DB 주소 — 설정되면 협업 메일 화면에 "규제 DB 연결되었습니다 🔴" 표시 (DB 미정, 현재 비워둠) | |

- 예시는 `.env.example`을 참고합니다. `.env`와 `data/`는 `.gitignore`에 포함되어 있습니다.
- 값은 `.env` → 환경변수 → Streamlit Secrets 순서로 찾습니다.
- Gmail은 대시보드 사이드바의 **📧 Gmail 연결 설정**에서도 입력할 수 있습니다. 입력 후 연결 테스트를 하고 `.env`에 자동 저장합니다.
- Gmail **API 키(Google Cloud)**가 아니라 **앱 비밀번호**를 사용합니다(SMTP 방식). 예전 키 이름 `GMAIL_ADDRESS` / `GMAIL_APP_PASSWORD`도 인식합니다.
- `.env`는 매 호출마다 다시 읽고 `core.py`도 실행 시마다 다시 불러오므로, 수정 후 서버를 재시작할 필요가 없습니다.

## 3. 기능

### 공통

- **로그인**: `APP_PASSWORD`가 설정되어 있으면 접속 시 비밀번호를 입력해야 합니다.
- **사이드바**: 메뉴, OpenAI(사용 모델 포함)·Gmail 연결 상태, Gmail 연결 설정, 현재 선택된 업체가 표시됩니다.
- 메뉴를 옮겨도 메일 초안·가이드·필터 등 입력값이 유지되며, 메뉴를 바꾸면 화면이 맨 위로 이동합니다.

### 3-1. 🔎 업체 컨택

- 케이터링 50곳과 인플루언서 72곳(현재 파일에는 `예시)` 테스트 행 1곳 포함 73곳)을 하나의 목록으로 불러옵니다. 상단에 업체 수와 이메일 보유 수가 표시됩니다.
- **구분** 버튼(케이터링 / 인플루언서)으로 하나 또는 둘 다 선택할 수 있습니다.
- **세부 카테고리** 칩으로 다시 걸러냅니다. 원본 카테고리 설명을 키워드로 자동 분류하며, 한 업체가 여러 태그를 가질 수 있습니다. 칩 옆에 해당 업체 수가 표시되고, 여러 칩을 고르면 하나라도 해당하는 업체가 모두 나옵니다(OR 조건).
  - 케이터링: 🎵 페스티벌·콘서트 · 🌙 나이트라이프·클럽 · 🎓 대학·테일게이트 · 💎 VIP·럭셔리·갈라 · 🍸 모바일 바·믹솔로지 · 🚀 브랜드 팝업·런칭 · 🏖️ 풀·비치·루프탑
  - 인플루언서: 🏢 대행사·매니지먼트 · 🧩 플랫폼 · 🎬 UGC·광고 소재 · 📣 PR·소셜 · 🌱 마이크로·제품 시딩 · 🍔 식음료·외식 · 🛒 TikTok Shop·DTC
  - 분류 키워드는 `core.py`의 `SUBCATEGORIES`에서 수정합니다.
- 업체명·지역·카테고리·이메일로 검색할 수 있고, **↺ 필터 초기화**로 조건을 한 번에 지웁니다.
- **이메일 셀을 클릭하면** 협업 메일 화면으로 이동하고 수신자가 자동으로 입력됩니다.
- 행을 선택하면 이메일·전화·URL·비고와 해당 업체의 협업 이력이 표시되고, **✉️ 협업 제안 메일 작성** 버튼으로 이동할 수 있습니다.
- 다른 업체를 선택하면 이전 메일 초안(제목·본문·번역)이 초기화되고, 같은 업체면 그대로 유지됩니다.

#### 데이터 매핑

| 내부 필드 | 케이터링 CSV | 인플루언서 XLSX |
| --- | --- | --- |
| `id` | `C` + No (3자리) | `I` + 번호 (3자리) |
| `name` | Company Name | 업체명 |
| `email` | Contact Email | 공개 이메일 |
| `phone` | Phone Number | 공개 전화/문자 |
| `url` | Official Website URL | 공식 사이트 URL |
| `location` | Office Location | 미국 시장 범위 |
| `category` | Category Focus | 서비스 형태 · 서비스/검토 이유 |
| `note` | Why Relevant | 주의/연락처 용도 |

> 인플루언서 파일에서 번호가 숫자가 아닌 행(예: `예시)` 테스트 행)은 `IX01`, `IX02` … id로 불러오며, 크리에이터 실적 더미 데이터에서는 제외됩니다.

### 3-2. ✉️ 협업 메일 › 메일 작성 탭

> 협업 메일 화면은 **✉️ 메일 작성 · 📘 협업 가이드** 2개 탭으로 구성됩니다. 탭을 오가거나 다른 메뉴에 다녀와도 메일 초안과 가이드가 유지됩니다.
> 제목 아래에 규제 DB 연결 상태가 표시됩니다: 연결되면 "규제 DB 연결되었습니다 🔴", 아니면 "규제 DB 연결되지 않았습니다 ⚪". 규제 DB가 아직 없으므로 현재는 "연결되지 않았습니다"로 표시되고, 검열은 로컬 `compliance_terms.csv` 기준으로 동작합니다. 통합 DB 연동 시 `.env`에 `REGULATION_DB_URL`을 설정하고 `core.has_compliance_db()`에 실제 접속 확인을 넣습니다.

1. **우리가 원하는 케이터링 업체 / 인플루언서**: 입력값이 프롬프트의 `{ideal}` 자리에 들어갑니다. 구분별 기본값이 채워져 있습니다.
2. **⚙️ 생성 프롬프트**: 업체 구분(케이터링 / 인플루언서)별로 다른 프롬프트를 사용합니다. "REBOOT 파트너십 책임자로서 ○○와 협업하고 싶다"는 비즈니스 톤입니다.
   - **📐 메일 구조** 카드로 생성 순서를 한눈에 확인합니다: 인사 → 회사 소개 → 협업 이유 → 제안(2–3개 항목) → 일정 → 다음 단계 → 맺음말
   - 프롬프트 원문은 펼쳐서 수정할 수 있습니다. 자리표시자: `{product}` 제품 설명 · `{ideal}` 원하는 파트너 · `{partner}` 업체명
   - **↺ 기본 프롬프트로 되돌리기**로 원래 프롬프트를 복원합니다.
   - 공통 규칙: 150–200단어, 섹션 이름 미출력, 의학·질병 주장 금지, 과음 조장 금지, **협업 목적·제안 내용·요청사항은 모든 항목을 반드시 반영**(한국어 입력은 영어로 번역)
3. **📎 첨부파일**: PDF, CSV, Word, Excel, PowerPoint, 이미지(PNG·JPG), ZIP, TXT를 올릴 수 있습니다.
   - 올린 파일은 첨부파일 보관함에 저장되고, 다음 메일에도 **기본 체크 상태로 자동 첨부**됩니다.
   - 이번 메일에서 빼려면 체크를 해제하고, 보관함에서 없애려면 삭제합니다.
   - 선택한 파일 수와 용량 합계가 표시되며, Gmail 한도인 25MB를 넘으면 경고합니다.
4. **협업 목적 · 기간 · 제안 내용 · 요청사항**: 구분별 비즈니스 문구가 기본으로 채워집니다. **기간**은 달력에서 고르며 오늘부터 30일 뒤까지가 기본값입니다.
5. **🤖 영문 제목·본문 생성**: OpenAI가 JSON(`subject`, `body`) 형식으로 생성하며, 수신자·제목·본문은 직접 수정할 수 있습니다. OpenAI 키가 없으면 직접 작성할 수 있습니다.
6. **🌐 번역**
   - **🇰🇷 한국어로 보기**: 영어 메일을 한국어로 확인합니다(참고용, 발송 본문은 그대로).
   - **🇺🇸 영어로 변환**: 한국어로 쓴 제목·본문을 영어로 교체합니다.
   - 번역 시 Markdown·줄바꿈, 브랜드명(REBOOT), 해시태그, URL, 할인코드는 그대로 유지합니다.
7. **🛡️ FDA 문구 점검**: 제목과 본문에서 금지·주의 표현을 찾아 등급·사유·수정 후보·문맥을 표시합니다.
8. 담당자를 입력하고 확인 체크 후 **📨 확인 — Gmail 발송**을 누릅니다. Gmail이 연결되지 않았으면 버튼이 비활성화됩니다.
9. 발송 성공이든 실패든 **협업 이력에 자동 저장**됩니다(첨부파일 이름, 발송 계정 또는 오류 내용, 답장 추적용 Message-ID 포함).

**↩️ 답장 모드**: 협업 이력의 회신 창에서 **✉️ 메일 화면에서 자세히 쓰기**를 누르면 이 화면이 답장 모드로 열립니다. 수신자·`Re:` 제목이 자동 입력되고 상단에 상대방 회신이 표시되며, 첨부파일과 함께 같은 Gmail 대화로 발송됩니다. **답장 취소**로 일반 작성으로 돌아갑니다.

### 3-3. ✉️ 협업 메일 › 📘 협업 가이드 탭

- 협업 유형(메일 탭에서 선택한 업체 구분이 기본값), 목적, 일정, 필수 전달사항, 결과물·제출 기준을 넣고 가이드 초안을 생성합니다.
  - **협업 목적**은 유형별 상황 6개 중에서 고르거나 **✏️ 직접 입력**합니다(선택지는 `core.py`의 `GUIDE_PURPOSES`에서 수정).
    - 인플루언서: 인지도·할인코드 매출 · 신제품 런칭 · 시즌 프로모션 · UGC 광고 소재 · 제품 시딩·리뷰 · TikTok Shop 라이브
    - 케이터링: 현장 샘플링 · 바 메뉴 입점 · 페스티벌·콘서트 부스 · VIP 파티 웰컴 키트 · 브랜드 팝업 공동 개최 · 대학·테일게이트 시즌
  - 가이드 구성(고정): 한 줄 요약 · 협업 개요(표) · 일정(표) · 핵심 메시지(한/영) · 결과물 및 제출 기준(표) · 표현 가이드 Do & Don't(표) · FTC 광고 표기 · 승인 절차 및 문의
- **📄 문서 미리보기** 탭에서 완성 문서 형태로 확인하고, **✏️ 원문 편집** 탭에서 Markdown 원문을 수정합니다.
- **🇺🇸 영어로 번역 / 🇰🇷 한국어로 번역**으로 가이드 전체를 번역합니다.
- **🛡️ 금지 표현 점검**(펼치기)에서 표현을 점검합니다.
- **✅ 확인 — 이메일에 첨부**를 누르면 가이드가 Word 파일(`REBOOT_{유형}_협업가이드_YYYYMMDD.docx`)로 변환되어 첨부파일 보관함에 저장되고, 메일 탭에서 체크된 상태로 함께 발송됩니다.
  - Word 서식: 표지(제목·발행일), 브랜드 색상 머리행 표, 요약 콜아웃, 머리글(REBOOT)·바닥글(Confidential · 페이지 번호), 맑은 고딕
- **⬇️ Word 다운로드 / ⬇️ Markdown**으로 내려받을 수도 있습니다(보관함에는 저장되지 않음).

### 3-4. 🗂️ 협업 이력 (자동 + 수기)

- 업체별·출처별(자동 / 수기 / 샘플)로 필터링합니다. **📥 답장 확인 (Gmail)** 버튼은 필터 오른쪽에 있습니다.
- **상태 두 가지**
  - **상태(메일)**: 🔵 발송 성공 / 🔴 발송 실패 / 🟠 반송 / 🟢 회신 받음 — 발송과 📥 답장 확인으로 **자동 갱신**. 🟡 회신 대기는 자동으로 붙지 않으며, 필요하면 편집 창에서 직접 지정합니다(답장 확인 대상에 포함).
  - **진행 상태(협업 단계)**: ⚪ 컨택 중 → 🟡 협의 중 → 🔵 협업 중 → 🟣 마케팅 진행 중 → 🟢 협업 완료 / 🟤 보류 / ⚫ 협업 중단 — 상세 편집·수기 입력으로만 변경 (메일 발송 시 '컨택 중', 회신에 답장하면 '협의 중')
- 표는 읽기 전용이며, 수정은 **✏️ 편집** 칸을 눌러 여는 편집 창에서만 합니다(활동·상태·진행 상태·담당자·일시·메모, 메일 기록은 제목·본문).
- **🟢 회신 받음** 칸을 누르면 회신 창이 열립니다.
  - 🤖 OpenAI가 회신을 한국어로 요약합니다(핵심 · 요청사항 · 분위기 · 다음 액션). 원문도 펼쳐 볼 수 있습니다.
  - 답장에 담을 내용을 한국어로 적고 **🤖 AI 답장 초안**을 누르면 영문 답장이 작성됩니다. 수정 후 **📨 답장 발송**하면 같은 Gmail 대화로 발송되고, 이력에 저장되며 진행 상태가 '협의 중'으로 바뀝니다.
  - 첨부파일이 필요하면 **✉️ 메일 화면에서 자세히 쓰기**로 협업 메일 화면의 답장 모드로 이동합니다.
- **⚙️ 표시 항목 · 순서**에서 항목을 빼거나 순서를 바꾸고, **↺ 초기화**로 되돌립니다.
- **삭제**: 행 왼쪽 체크박스로 여러 건을 고르고 **🗑️ 선택 삭제** → **삭제 확인**을 누릅니다. (예시용 샘플 4건은 DB 최초 생성 시 한 번만 추가되며, 현재 DB에서는 삭제된 상태입니다.)
- **➕ 수기 기록 추가**(접기/펼치기): 업체·활동 유형(전화·미팅·가이드 전달·메모·기타)·진행 상태·담당자·내용을 직접 기록합니다.
- **📥 답장 확인 (Gmail)**: '발송 성공·회신 대기' 상태인 발송 기록의 답장과 반송을 Gmail(IMAP, 같은 앱 비밀번호 사용)에서 찾아 상태를 갱신합니다.
  - 답장 → **회신 받음** + 메모에 회신 일시와 첫 문장(인용 원문 제외)
  - 반송 → **반송** + 메모에 반송 일시 (반송 알림의 실패 수신자 헤더 기준)
  - 발송 시 저장한 Message-ID로 정확히 매칭합니다. Message-ID가 없는 예전 기록은 수신자 주소 + 'Re:' 제목으로 추정하며, 메모에 '추정'으로 표시됩니다.
  - 전체보관함까지 검색하므로 보관 처리한 답장도 찾습니다. 메일은 읽음 처리하지 않습니다.
  - 열람(읽음) 여부는 개인 Gmail에서 정확히 확인할 방법이 없어 지원하지 않습니다.
- 저장소: `DATA_DIR/history.db`(SQLite). 새로고침하거나 다시 접속해도 유지됩니다.

### 3-5. 📈 크리에이터별 판매 실적

- 🧪 **현재는 더미 데이터**입니다. 인플루언서 상위 12곳 × 60일치 할인코드 주문(환불 약 5% 포함)과 방문 데이터를 사용합니다.
- 조회 기간을 고르면 위에서부터 **총 지표**(접속량·주문·판매량·매출) → **차트**(크리에이터별 매출, 일별 매출 추이) → **크리에이터별 표**(접속량, 주문 수, 판매량, 매출, 전환율) 순으로 표시됩니다(환불 주문 제외).
- Shopify를 연동하면 `core.dummy_sales()`를 Orders API(`discount_codes`) 호출로 교체합니다.

## 4. REST API (`server.py`)

| Method | Endpoint | 설명 |
| --- | --- | --- |
| GET | `/api/health` | OpenAI·Gmail 연결 상태 |
| GET | `/api/partners?type=&q=` | 업체 목록 검색 (`type`: 케이터링 / 인플루언서, `q`: 업체명) |
| POST | `/api/email/generate` | 영문 메일 생성 + 검열 결과 |
| POST | `/api/compliance` | 텍스트 금지 표현 점검 |
| POST | `/api/email/send` | Gmail 발송 + 이력 자동 저장 (첨부파일 미지원) |
| POST | `/api/replies/check` | Gmail 답장·반송 확인 + 이력 상태 갱신 |
| GET / POST | `/api/history` | 이력 조회(`?partner_id=`) / 수기 기록 추가 |
| GET | `/api/sales` | 크리에이터별 실적 집계 |

> API에는 인증이 없으므로 외부에 공개할 때는 별도 보호가 필요합니다.

## 5. 배포

### Render (대시보드, 권장)

1. 저장소를 GitHub에 올리고 Render → **New → Blueprint**에서 선택하면 `render.yaml`대로 생성됩니다.
2. Render 화면에서 `APP_PASSWORD`, `open_api`, `gmail_address`, `gmail_api` 값을 입력합니다(저장소에는 남지 않음).
3. **starter 이상 플랜**이 필요합니다. 무료 플랜은 Gmail 발송 포트(465/587)가 막혀 있고 영구 디스크가 없습니다.
4. 1GB 영구 디스크가 `/var/data`에 연결되고 `DATA_DIR=/var/data`로 설정되어, 재배포해도 이력과 첨부파일이 유지됩니다.

### 기타

- **Streamlit Cloud**: `app.py`를 지정하고, `.env` 대신 Secrets에 같은 키를 등록합니다. 파일 시스템이 초기화될 수 있으므로 운영 시에는 이력·첨부파일을 외부 DB와 스토리지로 옮겨야 합니다.
- **Flask API**: `Procfile`(`web: gunicorn server:app`)로 Render, Railway, Heroku 등에 배포합니다.

## 7. 남은 작업 · 확정 필요 사항

- **Shopify 연동**: API 접근 권한, 동기화 주기, 중복 주문 처리, 취소·환불 반영, 매출 계산 기준
- **방문 데이터**: 크리에이터별 UTM 또는 추적 링크의 출처와 귀속 기준. 연결 전에는 접속량이 더미 값입니다.
- **검열 DB 통합**: 통합 DB의 연결 정보와 갱신 방식, 검열 결과에 따른 발송 차단 여부
- **금지 표현 목록 검토**: 현재 `compliance_terms.csv` 25개 항목은 초안이므로 담당자 검토가 필요합니다.
- **가이드 점검 범위**: 가이드 안의 "금지 표현" 섹션 자체도 검열에 걸리므로, 해당 섹션은 점검에서 제외할지 결정해야 합니다.
- **REST API 정비**: 발송 API의 첨부파일 지원, API 인증
- **Gmail 발송 한도**: 개인 Gmail은 하루 약 500통입니다. 대량 발송이 필요하면 Workspace나 Gmail API(OAuth)로 전환합니다.

> 검열은 등록된 기준에 따른 표현 점검이며, 최종 검토는 담당자가 수행합니다.
