# 주간 성과 보고서 (성과분석)

> 담당: 혁주 (HJ)

REBOOT 대시보드의 **📈 성과분석** 화면과 **📄 성과 보고서(A4 · PDF)** 설명서입니다.
채널별 광고비 · 매출 CSV를 올리면 지표 계산, 차트, 잘한 점 · 개선할 점, AI 예산 제안까지 자동으로 만들어 줍니다.

대시보드 전체 설명과 설치 · 배포 방법은 [README.md](README.md)를 참고하세요.

---

## 1. 한눈에 보기

| 화면 | 주소 | 용도 |
|---|---|---|
| 성과분석 | `/performance.html` | 기간을 바꿔 가며 지표 · 차트를 보고 분석하는 화면 |
| 성과 보고서 | `/report.html?start=YYYY-MM-DD&end=YYYY-MM-DD` | 공유 · 인쇄용 A4 문서. 브라우저 인쇄로 PDF 저장 |

성과분석 화면 구성 (위에서 아래 순서)

1. **기간 선택**: 달력 · 최근 7일 · 매출 CSV 업로드 · 양식 받기 · 보고서 만들기
2. **기본 정보**: 보고 기간 · 비교 기간 · 작성일
3. **핵심 지표 6개**: 총 광고비 · 총 매출 · ROAS · 전환수 · CPA · 순수익 (비교 기간 대비 증감)
4. **채널별 성과 표**: 원화 / 달러 전환 · 환율 확인 · 행 클릭으로 채널 선택
5. **차트**: 채널별 광고비 대비 매출(막대) · 일별 매출 추이(선)
6. **잘한 점 / 개선할 점**: AI 컨설턴트 해석
7. **AI 제안 · 다음 주 예산 배분**: 총평 · 채널별 예산 · 실행 과제

## 2. 사용 방법

### 기간 고르기

- 처음 열면 **CSV 마지막 날짜 기준 최근 7일**이 선택됩니다.
- 시작일 · 종료일 달력에서 원하는 기간을 **직접** 고를 수 있습니다. CSV에 있는 날짜 범위 밖은 고를 수 없습니다.
- **비교 기간**은 고른 기간 바로 앞의 **같은 길이** 기간입니다.
  - 예: 10/15 ~ 10/21(7일) → 비교 10/08 ~ 10/14, 표시는 "전주 대비"
  - 예: 10/10 ~ 10/12(3일) → 비교 10/07 ~ 10/09, 표시는 "직전 기간 대비"
- 비교 기간이 CSV 시작일보다 앞으로 나가면 일부 날짜만 비교되어 숫자가 왜곡되므로 **비교하지 않고 "데이터 없음"**으로 표시합니다.
- **최근 7일** 버튼을 누르면 처음 상태로 돌아갑니다.

### 채널별 성과 표

- **원화 / 달러**: 광고비 · 매출 · CPA를 달러로 바꿔 봅니다. ROAS · CTR · CVR은 비율이라 그대로입니다.
- **환율 확인**: 한국수출입은행 최신 고시 환율을 다시 받아와 표에 반영합니다. 옆에 `1$ = 1,324.6원 · 수출입은행 2026-10-23 기준`처럼 기준일이 표시됩니다.
- **행 클릭**: 그 채널을 선택해 아래 일별 추이 차트에 반영합니다. 다시 누르면 선택 해제, 여러 채널 동시 선택 가능합니다.
- 현재 달러 표시는 이 표에만 적용됩니다. 핵심 지표 · 차트 · 보고서는 원화입니다.

### 일별 매출 추이 차트

| 상태 | 보이는 선 |
|---|---|
| 채널 선택 없음 | 채널별 **매출** 선 (채널끼리 비교) |
| 채널 선택 | 선택한 채널마다 **매출(실선)** + **광고비(점선)**, 같은 색 |

범례 항목을 누르면 그 선을 숨기거나 다시 보여 줍니다. 예: "매출"만 남기기, "매출 + 광고비"만 남겨 비교하기.

### AI 해석 · 예산 제안

- 화면을 열면 먼저 숫자 기준 문구(ROAS 최고 · 최저 채널)가 나오고, AI 응답이 오면 **컨설턴트 해석**으로 바뀝니다(`AI` 배지).
- AI 제안에는 총평, **다음 주 총 예산 · 이번 주 광고비 · 증감** 요약, 채널별 **제안 예산 · 이번 주 대비 증감 · 비중 막대 · 근거**, **실행 과제 카드**가 나옵니다.
- 같은 기간의 AI 결과는 같은 날 같은 브라우저 탭에서 다시 쓰므로 새로고침해도 다시 호출하지 않습니다. 새로 받으려면 **다시 만들기**를 누릅니다.
- AI 호출이 실패하면 숫자 기준 문구가 그대로 남고, 제안 칸에 실패 이유가 표시됩니다.

### 보고서 만들기 · PDF

1. 성과분석에서 기간을 고른 뒤 **📄 보고서 만들기 · PDF**를 누릅니다. 고른 기간이 그대로 보고서로 넘어갑니다.
2. 보고서 화면 목록에서 다른 주를 고를 수도 있습니다. 성과분석에서 직접 고른 기간은 목록 맨 위에 **(직접 지정)**으로 들어갑니다.
3. **인쇄** → 대상 "PDF로 저장"을 고르면 A4 PDF가 만들어집니다.

## 3. 데이터: performance.csv

### 형식

첫 줄(헤더)은 반드시 아래 순서여야 합니다. **양식 받기** 버튼으로 빈 양식을 받을 수 있습니다.

```csv
날짜,채널,광고비,노출수,클릭수,전환수,매출
2026-10-19,Instagram,300000,52000,1300,42,1260000
```

| 열 | 내용 | 비고 |
|---|---|---|
| 날짜 | `2026-10-19` | `2026/10/19`, `2026.10.19`도 자동 변환 |
| 채널 | 광고 채널 이름 | 표 · 차트 · AI 예산에 이 이름 그대로 사용 |
| 광고비 · 매출 | 원 단위 정수 | `1,260,000` · `1260000원`도 읽음 |
| 노출수 · 클릭수 · 전환수 | 정수 | |

엑셀에서 저장한 CSV(EUC-KR)도 그대로 올릴 수 있습니다.

### 업로드

**📤 매출 CSV 업로드** → 파일 선택 → 방식 선택

| 방식 | 동작 |
|---|---|
| 합치기 | 기존 데이터에 추가. 같은 **날짜 + 채널**이 있으면 새 값으로 덮어씀 |
| 전체 바꾸기 | 기존 데이터를 지우고 새 파일로 교체 |

덮어쓰기 전 이전 파일은 서버의 `db/backups/performance-YYYYMMDD-HHMMSS.csv`에 자동 보관됩니다.

## 4. 지표 계산식

| 지표 | 계산식 |
|---|---|
| ROAS | 매출 ÷ 광고비 × 100 (%) |
| CTR | 클릭수 ÷ 노출수 × 100 (%) |
| CVR | 전환수 ÷ 클릭수 × 100 (%) |
| CPA | 광고비 ÷ 전환수 (원) |
| 순수익 | 매출 − 광고비 (원) |
| 증감률 | (이번 기간 − 비교 기간) ÷ 비교 기간 × 100 (%) |

- 합계 행의 ROAS · CTR · CVR · CPA는 채널 평균이 아니라 **합계 값으로 다시 계산**합니다.
- CPA는 **낮을수록 좋음**이라 감소(▼)가 초록색입니다. 총 광고비 증감은 좋고 나쁨이 없어 회색입니다.

## 5. AI (OpenAI)

| 항목 | 내용 |
|---|---|
| 모델 | `js/config.js`의 `OPENAI_MODEL` (기본 `gpt-4o-mini`) |
| 페르소나 | 10년 경력의 해외 마케팅 담당자 · 성과분석 전문 컨설턴트 |
| 분석 관점 | 퍼널(노출 → 클릭 → 전환) 단계별 원인, 주어진 숫자에만 근거 |
| 입력 | 기간 합계 · 비교 기간 · 채널별 지표 · 다가오는 미국 음주 시즌(`data/season_calendar.csv`) |
| 호출 | 한 번 호출로 해석 + 예산 제안을 JSON으로 받음 |

AI가 돌려주는 항목

| 항목 | 내용 |
|---|---|
| `overview` | 이번 기간 성과 총평 2~3문장 |
| `analysis.good` | ROAS 최고 채널 해석 · 강점 키우는 방법 |
| `analysis.improve` | 개선이 가장 시급한 채널 · 퍼널 문제 지점 · 개선 방향 |
| `budget` | 다음 주 채널별 예산(원). 총액은 이번 기간 광고비의 ±20% 안 |
| `actions` | 다가오는 시즌 대비 실행 과제 2~3개 |

프롬프트는 `js/metrics.js`의 `getBudgetAdvice`에 있습니다. 문구를 바꾸면 화면과 보고서에 함께 반영됩니다.

## 6. 환율 (한국수출입은행)

- 서버 `GET /api/fx`가 수출입은행 현재환율 API의 **USD 매매기준율**을 돌려줍니다.
- 수출입은행 환율은 **영업일 오전 11시쯤 하루 한 번** 고시됩니다. 분 단위 실시간 환율은 아닙니다.
- 주말 · 공휴일 · 고시 전에는 당일 데이터가 없어 **가장 최근 영업일** 환율을 자동으로 찾습니다(최대 7일 전까지).
- 키가 없거나 조회에 실패하면 **1,400원**으로 계산하고 `기본값 (이유)`를 표시합니다.

## 7. 서버 API (Flask · app.py)

모두 로그인한 상태에서만 동작합니다. 로그인 안 됨 → `401`.

| 메서드 · 주소 | 용도 |
|---|---|
| `GET /data/performance.csv` | 성과 데이터 (업로드한 파일이 있으면 그 파일) |
| `PUT /api/performance` | 성과 CSV 저장. 본문 `{ "csv": "..." }`, 헤더가 다르면 `400` |
| `POST /api/openai` | OpenAI Chat Completions 대리 호출 (키는 서버에만 있음) |
| `GET /api/fx` | USD 환율 `{ status: "ok", rate, date }` · `no_key` · `error` |

## 8. 환경 변수

로컬은 `.env`, Render는 서비스의 **Environment**에 넣습니다. 목록은 `.env.example` 참고.

| 이름 | 성과분석에서 쓰는 곳 | 없으면 |
|---|---|---|
| `OPENAI_API_KEY` | AI 해석 · 예산 제안 | 숫자 기준 문구만 표시, AI 칸에 안내 |
| `KEXIM_API_KEY` | 달러 환율 | 1,400원 기본값 |
| `DATA_DIR` | 업로드한 CSV · 백업 저장 위치 (Render Persistent Disk) | 프로젝트 폴더에 저장 |

> **Render 무료 플랜 주의**: 재배포 · 재시작 때 업로드한 CSV와 백업이 사라지고 저장소의 기본 `tabs/performance/data.csv`로 돌아갑니다. 유지하려면 Persistent Disk + `DATA_DIR`이 필요합니다.

## 10. 문제 해결

| 증상 | 확인할 것 |
|---|---|
| "성과 데이터가 아직 없어요" | `tabs/performance/data.csv`가 비었거나 없음 → CSV 업로드 |
| "이 기간에는 CSV 데이터가 없어요" | 고른 기간에 해당 날짜 행이 없음 → 기간 변경 |
| 업로드 시 "첫 줄은 … 이어야 합니다" | 헤더 순서 · 철자 확인 (양식 받기 사용) |
| AI 칸에 "OpenAI 가 연결되어 있지 않습니다" | `OPENAI_API_KEY` 설정 후 새로고침 |
| 환율 옆에 "기본값 (…)" | `KEXIM_API_KEY` 확인. "인증키 오류"면 키 오타, "한도 초과"면 하루 1,000회 초과 |
| 비교 기간 "없음" | 비교 기간이 CSV 시작일보다 앞 → 정상 동작 (왜곡 방지) |
| 코드 수정이 화면에 안 보임 | 브라우저 캐시 → `Ctrl + F5` |
