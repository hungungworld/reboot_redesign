# 알디콤 US 마케팅 대시보드: 시장 · 고객 인사이트 (담당: 현경)

> 담당: 이현경 (HK)

미국 시장에서 알디콤의 **진열대(경쟁 제품·가격) · 고객 반응(리뷰·유튜브) · 검색 수요**를 매주·매월 모아 보여주고,
마케터가 할 일을 정리해 주는 대시보드입니다. 이 문서는 **3번째 대시보드**(업무 주기별 구성)를 기준으로 설명합니다.

> **이름 규칙:** 이 문서의 **알디콤**은 실제로 수집하는 자사 기준 제품이에요. 발표 화면에서는 리브랜딩 이름 **REBOOT**로 표기하고, REBOOT 젤리·음료 4종을 가상 출시했다고 가정해요. 시장·경쟁사·리뷰 데이터는 모두 실제예요. 자세한 내용은 설정 README를 보세요.

- **화면:** `web/` (HTML·CSS·JS)
- **서버:** `server.py` (Python). 데이터 수집과 AI 호출을 서버가 맡아요. 브라우저만으로는 API 키가 노출되고, 다른 사이트 수집이 막혀서예요.

---

## 실행

```bash
pip install -r requirements.txt
python server.py
```

http://localhost:8000 이 자동으로 열려요. 종료는 `Ctrl+C`.
사이드바 맨 위에서 **3번째 대시보드**를 고르세요. 마지막에 고른 버전이 기억돼요.

## API 키

**설정 › 연결**에서 키를 입력하는 게 기본이에요. 저장한 키는 끝 4자리만 보이고, 서버에 암호화해서 저장돼요.
`.env`에 넣어둘 수도 있어요. 화면에서 입력한 키가 `.env`보다 우선이에요. `.env`는 공유하지 마세요.

```
OPENAI_API_KEY=...
OPENAI_MODEL=gpt-5.4-mini      # 선택 (기본 gpt-5.5)
YOUTUBE_API_KEY=...
FIRECRAWL_API_KEY=...
SERPAPI_KEY=...
```

| 키 | 쓰는 곳 | 무료 한도 | 없으면 |
|---|---|---|---|
| `OPENAI_API_KEY` | 이번 주 액션, 한 줄 정리, 한국어 정리, 리뷰 분류, 월간 요약·전략 | 유료 (사용량 과금) | AI 기능이 꺼져요 |
| `FIRECRAWL_API_KEY` | Weee! 진열대 (목록·가격·재고·핵심 메시지·구매자 리뷰) | 월 1,000 크레딧 (학생 1만) | Weee! 수집이 안 돼요 |
| `SERPAPI_KEY` | Amazon 진열대·대표 리뷰, Google 검색 트렌드 | 월 250회 | 검색 트렌드는 Google Trends CSV로 대체 |
| `YOUTUBE_API_KEY` | 유튜브 영상 검색·댓글 (월간) | 하루 10,000 units | 비공식 대체 경로 (시연용) |
| `SLACK_WEBHOOK_URL` | 리뷰 카드 › 슬랙으로 보내기 (미리 보기 확인 후 사람이 보냄) | 무료 (무료 플랜은 앱 개수 제한) | 버튼이 안 보여요 |

키 상태와 남은 사용량은 **설정 › 연결**에서 테스트할 수 있어요. 슬랙 웹훅은 api.slack.com/apps → 앱 만들기(Blank app) → Incoming Webhooks 켜기 → Add New Webhook(채널 고르기) → 주소 복사 → `.env`의 `SLACK_WEBHOOK_URL=` 또는 설정 › 연결. 주소가 있으면 누구나 그 채널에 글을 올릴 수 있으니 공유하지 마세요 (새어 나가면 그 웹훅을 지우고 새로 만들기). 키 입력·암호화, Gmail 로그인은 설정 README를 보세요.

## 3번째 대시보드 한눈에 보기

```
시장 · 고객 인사이트
├── 주간 리뷰 ──── 매주 월요일 · 15분 · "이번 주 무엇을 해야 하나"
├── 월간 리뷰 ──── 매월 첫 주 · 1시간 · "지난 한 달 무엇이 달라졌나"
└── 데이터 ─────── 필요할 때 · 숫자의 원본과 근거
설정
├── 수집 설정 ──── 검색어 세트 · 영상 선정 기준 · Amazon 검색어/추적 ASIN · 트렌드 키워드 · 시즌
├── 제품 정보 ──── 브랜드 기본 정보 · REBOOT 4종 팩트시트 (기사·공식 정보 기반 / 가격·원가는 가상값)
├── 연결 ────────── API 키 입력 · 연결 테스트 · Gmail 로그인
└── 작업 로그 ──── 수집 · AI 프롬프트 · 승인 기록(자동/수동) (과제 제출용)
```

설정 탭의 자세한 내용은 설정 README에 있어요. 알디콤의 **실제 판매가**는 팩트시트가 아니라 이 탭(진열대)에서 수집해 보여줘요.

### 주간 리뷰 (매주 월요일)

| 영역 | 내용 |
|---|---|
| **이번 주 액션** | 판단은 **규칙**이 하고, AI는 문장만 써요. 신호마다 **긴급 / 기회 / 참고** 등급과 **사실 → 영향 → 할 일**을 보여줘요. 걸린 신호가 없으면 "특이사항 없음"이에요. |
| 진열대 변화 | 경쟁 제품 품절(재입고) · 재고 임박 · 가격 변동 · 신규 진입 수, 주목할 제품(품절 · 옵션 품절 · 재고 임박), Weee!에서 알디콤의 1회분 단가 위치. 숫자가 비면 **데이터가 부족한 곳**에 이유와 할 일(미수집 판매처 · 첫 수집 · 재고 미확인 · 자사 미발견 · 묶음 확인 전)을 보여줘요 |
| 새 리뷰 | 지난 7일 새 리뷰 수, 칭찬·불만 상위 주제 |

**이번 주 액션 규칙**
- 알디콤 품절 + 45일 안에 시즌 → 긴급
- 경쟁사 가격 ±10% 이상 변동 → 인하는 긴급, 인상은 참고
- 신규 제품 진입 → 참고
- 작년에 검색이 평균보다 20% 이상 늘었던 시즌이 30일 안에 옴 → 기회
- 유튜브 댓글 최다 질문 → 기회
- 알디콤 리뷰 불만 1위 → 긴급
- 경쟁 제품 품절: 한 채널 → 기회 (입찰 상향 · '즉시 출고' 소재 · 쿠폰 보류 검토), 같은 제품이 2채널 이상 → 긴급 (외부 광고 랜딩 · 묶음 구성 검토). 지난 수집에도 품절이면 "계속 품절"
- 경쟁 상품 재고 임박 (Amazon "Only N left", N ≤ 20) → 참고 ("경쟁 제품 품절에 대비하세요")
- 경쟁 상품 재입고 (지난 수집 품절 → 이번 재고 있음) → 참고 (올린 입찰가 · 보류한 쿠폰 되돌리기)
- 광고 소재를 권하는 할 일에는 "효능 표현 · 경쟁 브랜드 이름은 컴플라이언스 탭 검토"를 붙여요

**제품 묶음 (`lines.py`)** — 품절은 상품 하나가 아니라 **제품** 기준이에요.
- 제품 = 브랜드 + 제형 (예: 상쾌환 · 환). 브랜드 별칭은 `data/product_lines.json` (Q.one · Easy Tomorrow · Qone → 상쾌환). 제형에 **환(Pellet)** 이 있어요
- 옵션 = 회분 수 (10포 · 20포). 맛 · 버전은 나누지 않아요. 한 옵션에 여러 상품이면 "2개 중 1개 품절"
- 판매처의 상품이 모두 품절일 때만 그 채널을 품절로 봐요 (옵션 일부만 품절이면 '옵션 품절')
- 자동으로 묶고, 진열대 › 표로 보기 › 묶음 칸에서 고치거나 **묶음 모두 확인**을 눌러요. 확인 · 수정은 모든 주차에 적용돼요

**버튼**
- **데이터 업데이트:** 확인 창에서 항목을 고르고, 비용과 이번 달 남은 사용량을 본 뒤 시작해요. 항목은 Weee! 진열대·리뷰 · Amazon 진열대·리뷰 · Yami 진열대 · 채널 리뷰(Olive Young · Amazon · Yami) · 검색 트렌드 · 리뷰 분류 · 이번 주 액션이에요.
- **주간 리포트 받기:** Word 1장

> 검색 수요 탭은 2026-10-25에 삭제했어요. **다음 급등 예상**(작년 같은 시기 대비 %)은 **홈 › 콘텐츠 캘린더 맨 아래**(접기)로 옮겼어요. 검색 트렌드 수집과 `/api/insights/data/trends`는 그대로예요.

**경쟁사 분석** — 마케터가 알고 싶은 것(무슨 말로 · 얼마에 · 어디서 팔고, 고객은 어떻게 보나 · 이번 주 무엇이 바뀌었나)만 보여 줘요. 제품 기획용 매트릭스 · 블루오션 · 섭취 타이밍은 넣지 않아요.
- **경쟁사 찾기:** Amazon · Yami 진열대에 나온 브랜드를 자동 등록해요 (무료). Weee!에서 잡히면 가격 비교에 보태요. 대체재 검색어(`electrolyte drink hangover` · `liver support supplement`)로만 잡힌 브랜드는 '대체재'로 따로 둬요.
- **사실 칸 (수집 데이터 그대로):** 판매 채널별 최저가 · 판매량(Yami), 1회분 단가, 제형(Liquid · Powder · Gummy/Jelly · Tablet/Capsule · 기타 — 상품명 규칙, 못 정한 상품만 AI), 고객 칭찬/불만(구매자 리뷰 분류), 유튜브 언급(영상 제목 · 댓글에서 브랜드 이름이 나온 수).
- **분석 칸 (리뷰 상위 15개 브랜드):** 핵심 메시지 · 주력 성분 · 기타 판매처 · 최근 소식은 ① 진열대(P) · 리뷰 요약(S) · 구매자 리뷰(R) · 브랜드 홈페이지(W) · 뉴스 검색(N) 근거 안에서 AI가 채우고 ② 못 채운 칸만 **OpenAI 웹 검색**(G, 출처 링크 필수)으로 채워요 ③ 그래도 없으면 '공개 자료에서 찾지 못함'으로 적어요(지어내지 않음). '알디콤이 쓸 말 / 피할 말'은 AI 의견이에요.
- **검색어:** Amazon은 `data/competitor_keywords.json`의 11개를 설정 › 수집 설정 › Amazon 검색어에 넣어 써요. Yami는 같은 파일의 `yami_queries`(지금 `hangover` · `hangover jelly`)예요.
- **다시 조사:** 데이터 업데이트 '경쟁사 분석'은 25일이 지난 곳만, '전체 다시 조사'는 15개 모두, 카드의 '다시 조사'는 한 곳만. 이전 분석과 달라진 항목을 기록해요. 근거가 그대로면 저장된 결과를 써서 비용이 들지 않아요.

**한 줄 정리:** 데이터가 바뀌었을 때만 AI가 다시 써요. 같은 데이터면 저장된 문장을 보여줘서 비용이 들지 않아요.

## 데이터는 어디서 오나

|---|---|---|---|
| Weee! 진열대 | Firecrawl: 숙취 카테고리 2페이지 + 주요 상품 페이지 10개 (재고·핵심 메시지) | 주 1회 | 카테고리는 매번 보이는 제품이 달라서 알디콤은 상품 페이지로 따로 수집. 음식(해장국)은 제외. 사이트가 weee.com으로 바뀌고 상품 카드 전체가 링크라서 카드 안에서 가격 · 품절을 읽어요 (2026-10-24). 검색 목록은 숙취 관련 말이 있는 상품만 남겨요 |
| Amazon 진열대 | SerpApi: "hangover" · "korean hangover" 검색 상위 (광고 제외 각 8개) + 많이 팔린 6개 상품 조회 | 주 1회 | **알디콤은 아마존 검색에 나오지 않아요 (2026-10-23 기준).** ASIN을 알면 수집 설정 › 추적 ASIN에 넣으세요 |

| 채널 리뷰 (알디콤) | `data/review_sources.json`의 알디콤 상품 — Olive Young 6 · Yami 1(Firecrawl) · Amazon 1(SerpApi) | 주 1회 | Olive Young은 **영어 리뷰만** 끝까지(더 보기를 자바스크립트로 누름), 영어 리뷰가 0개인 상품은 한국 리뷰가 대신 보여서 읽지 않아요. Yami는 리뷰가 생기면 JSON 추출로 읽어요. 작성자 이름은 저장하지 않아요 Amazon은 대표 리뷰(최대 8개 · 매주 새 것만 더함)예요 |
| 검색 수요 (홈 › 다음 급등 예상 · 주간 리뷰) | SerpApi Google Trends (미국 · 12개월) | 주 1회 | 키워드마다 **따로 조회** — 같이 조회하면 큰 키워드가 작은 키워드를 납작하게 만들어요 |

| Yami 진열대 | Firecrawl: `yami_queries` 검색 결과 첫 페이지 (브랜드 · 가격 · 정가 · 판매량) | 주 1회 | robots.txt가 리뷰(`/comment/`)는 막아서 진열대만 읽어요. 숙취 · 음주 · 간 관련 단어가 없는 상품은 빼요 |
| 경쟁사 분석 | 진열대 · 리뷰 + Firecrawl(홈페이지 찾기 · 읽기 · 뉴스 검색) + OpenAI(분석 · 못 채운 칸 웹 검색) | 주 1회 (25일 지난 곳만) · 버튼 | 브랜드마다 OpenAI 1~2회 · Firecrawl 2~3회. AI 결과라 카드의 근거 자료로 꼭 확인 |
| 페르소나 그림 (월간 리뷰) | `static/peeps/peep-01~12.svg` — [Open Peeps](https://www.openpeeps.com/)(Pablo Stanley, CC0 1.0)를 DiceBear `open-peeps`로 만든 것 | 한 번 (2026-10-25) | 머리는 무난한 12종(짧은 · 중간 · 긴 · 앞머리 · 묶은 머리), 표정은 calm · smile만. 옷 색은 `currentColor`라 카드 색을 따라가요. 이름으로 12개 중 하나를 골라요 |

**1회분 단가 계산**
- **기본:** 포장 문구에서 개수를 읽어 계산해요. 예) `5 pack*4 boxes` = 20, `Pack of 6` = 6, `(min 2)`는 최소 주문 수량이라 무시
- **보충:** 문구에서 못 읽으면 한국어 이름("20팩")에서 가져와요. 한 번 확인된 개수는 기억해요.
- **수정:** 틀리면 진열대 › 표로 보기에서 바로 고칠 수 있어요.

## 알려진 한계

- **변화 알림은 2주차부터:** 가격·품절·신규 알림과 월간 지표는 주간 데이터가 쌓여야 의미가 생겨요. 첫 주에는 비교할 지난주가 없어요.
- **회분 수 확인 필요:** 큐원 망고 젤리, 지바이오틱스, 블로피쉬는 묶음 구성을 확인하지 못해 1회분으로 잡혀 있어요.
- **알디콤 1박스 구성 불일치:** Weee! 상품 페이지 "21 ml × 4 Sachets"와 목록 "1 pack*5 pack"이 달라요. 지금은 4포 기준이에요.
- **경쟁사 홈페이지는 첫 화면만 읽어요:** 못 채운 칸은 OpenAI 웹 검색으로 보충하고, 출처 링크가 없는 답은 버려요.
- **칭찬/불만은 수집한 리뷰 기준이에요:** Amazon은 상세 조회한 상품의 대표 리뷰만 있어서, 상세 조회 수(설정 › 수집 설정)를 늘리면 더 많은 브랜드가 채워져요. Yami 리뷰는 robots.txt 때문에 읽지 않아요.
- **AI 문장은 근거 데이터와 함께 확인하세요:** 판단 규칙과 AI에 넘긴 사실은 "규칙에 걸린 신호 보기" · "근거 보기"에서 볼 수 있어요.
- **검색 트렌드의 이유는 추정이에요:** 급상승 검색어가 급등한 그 주가 아니라 12개월 전체 기준이에요.
