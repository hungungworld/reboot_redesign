======================================================================
1. KPI 카드 (home.js paintKpis)
======================================================================

1-1. 이번 주 매출 · 광고 수익률(ROAS) · 주간 차트
  가져오는 함수 : REBOOT.use('performance').weekSummary(), .summary({start, end})
  API 주소      : GET /api/performance/summary  (?start=YYYY-MM-DD&end=YYYY-MM-DD)
  실제 데이터   : 업로드한 CSV (DATA_DIR/uploads/performance/performance.csv)
                  없으면 tabs/performance/data/performance_sample.csv  [더미]
  담당 탭       : 성과분석 (HJ) — 경로는 tabs/performance/csvdata.py
  메모          : 샘플이면 카드 아래에 "샘플 데이터"라고 표시됨

1-2. 진행 중인 캠페인
  가져오는 함수 : REBOOT.use('content').campaigns()
  API 주소      : GET /api/content/campaigns
  실제 데이터   : DB 표 content_campaigns — '제작 중' + '검토 중' 개수
  담당 탭       : 콘텐츠 제작 (NW)
  메모          : 값을 못 받으면 이 칸은 '준비 중인 시즌'(1-4)으로 바뀜

1-3. 검토가 필요한 업무
  가져오는 함수 : REBOOT.use('cs').stats().open
  API 주소      : 없음 (서버를 거치지 않음)
  실제 데이터   : 브라우저 저장소 — tabs/cs/static/cs.js 의 seed() 가 만든 가짜 문의  [더미]
  담당 탭       : 고객 응대 (JH)
  메모          : PC·브라우저마다 숫자가 다를 수 있음
                  컴플라이언스 '카피 검토 대기'는 컴플라이언스 탭이 summary()를 없애서
                  지금은 안 들어옴 (home.js compliancePending() 은 항상 null)

1-4. 준비 중인 시즌 (1-2 대신 나올 때)
  → 2. 시즌 캘린더와 같은 데이터

3. 미국 주류 업계 뉴스  [외부]
======================================================================
  API 주소      : GET  /api/home/news          저장된 결과만 (구글 뉴스를 부르지 않음)
                  POST /api/home/news/collect  지금 수집
                  GET  /api/home/news/status   수집 상태
  외부 출처     : 구글 뉴스 RSS (키 필요 없음)
                  https://news.google.com/rss/search?q={검색어} when:{기간}&hl=en-US&gl=US&ceid=US:en
                  업계지 RSS 6곳 (2026-10-24 추가 · robots.txt 확인 · 키 필요 없음)
                    업계 뉴스: BevNET, NutraIngredients-USA
                    트렌드 칸: Marketing Dive, Modern Retail, Mintel, NOSH
                  (Beverage Industry 등은 봇 차단 403이라 뺌)
  검색어·제외어 : tabs/home/data/queries.json (피드 주소도 여기)
  저장          : DB 표 home_news_articles, home_news_runs (90일 보관)
  AI            : OpenAI (OPENAI_API_KEY 있을 때만) — 관련 기사 고르기 + 한국어 요약
